# FaultGlass

Compare reproducible cases across FalkorDB engines and inspect the paired evidence.

- [Local comparison setup, approved images, and evidence verification](apps/investigator/README.md)
- [Persistent investigation memory, graph model, and recovery](apps/investigator/CONTEXT.md)
- [Frontend setup](apps/web/README.md)

The local execution foundation provides strict case validation, isolated disposable engines, deterministic comparison, and hashed filesystem evidence. A baseline is not automatically an oracle, and a difference alone is not proof of a regression.
